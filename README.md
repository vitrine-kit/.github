# .github

Организационные defaults для [@vitrine-kit](https://github.com/vitrine-kit).

- `profile/README.md` — публичная страница профиля организации (рендерится на
  [github.com/vitrine-kit](https://github.com/vitrine-kit)).
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `.github/ISSUE_TEMPLATE/`,
  `.github/PULL_REQUEST_TEMPLATE.md` — community health files, которые **наследуются всеми
  репозиториями** организации, где нет собственных версий.

> Как развернуть: создайте в организации репозиторий с именем **`.github`**, положите в него
> содержимое этой папки и запушьте в `main`.
