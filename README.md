# .github

Organization defaults for [@vitrine-kit](https://github.com/vitrine-kit).

- `profile/README.md` — the public organization profile page (rendered on
  [github.com/vitrine-kit](https://github.com/vitrine-kit)).
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `.github/ISSUE_TEMPLATE/`,
  `.github/PULL_REQUEST_TEMPLATE.md` — community health files that are **inherited by all
  repositories** of the organization that don't have their own versions.

> How to deploy: create a repository named **`.github`** in the organization, put the
> contents of this folder into it and push to `main`.
