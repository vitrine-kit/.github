# Support

Where to get help with [@vitrine-kit](https://github.com/vitrine-kit) projects.

## Documentation

- **[Website](https://vitrine-kit.github.io/vitrine/)** — product overview, tiers, and how the kit fits agency work
- **[Developer wiki](https://vitrine-kit.github.io/vitrine/developers/)** — quickstart, CLI, architecture, contracts

## Bugs and features

Open an issue on the relevant repository (usually
[vitrine](https://github.com/vitrine-kit/vitrine/issues)) using the bug-report or
feature-request template.

Before filing:

1. Search existing issues.
2. For client-repo problems, run `vitrine doctor` and include the output when useful.
3. Note package / CLI versions (`@vitrine-kit/*`, `vitrine --version`).

## Security

**Do not open a public issue for vulnerabilities.** Follow
[SECURITY.md](SECURITY.md) (private GitHub advisory only).
